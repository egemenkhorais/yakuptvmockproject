# yakuptvmockproject

## Description
This project focuses on computer vision pose estimation and real-time matching.

## Modules
**poz_ortak.py**: Shared pose utilities and landmark detection.

**hafiza_olustur.py**: Creating reference pose templates.

**live_match.py**: Real-time camera matching.

## Requirements
Python 3.8, OpenCV, MediaPipe, NumPy

## Execution Steps
Step 1: Install requirements (Python 3.8, OpenCV, MediaPipe, NumPy).

Step 2: Create reference pose templates by running hafiza_olustur.py.

Step 3: Run live_match.py for real-time camera matching.
